# Problem Statement

Write a solution to find the people who have the most friends and the most friends number.

The test cases are generated so that only one person has the most friends.

**Link:** [Friend Requests II](https://leetcode.com/problems/friend-requests-ii-who-has-the-most-friends/description/?envType=problem-list-v2&envId=weh5ncag)

---

## Approach 1 (COUNT Approach):

* Both the `requester_id` column and the `accepter_id` column contain the `user_id`s. For our result, we need to count both, so we will use `UNION ALL` to combine them into the same column `id`. We will use this in a CTE or subquery. I prefer a subquery.
    
* Next, we will count the occurrences of all the `id`s, then use `ORDER BY DESC` and limit it to 1 row to get the answer.
    

### Solution Code:

```sql
WITH mixed AS (
    SELECT requester_id AS id FROM RequestAccepted
    UNION ALL
    SELECT accepter_id AS id FROM RequestAccepted
)

SELECT id, COUNT(id) AS num
FROM mixed
GROUP BY id
ORDER BY num DESC LIMIT 1
```

---

## Approach 2 (Window Functions):

**Follow up:** In the real world, multiple people could have the same most number of friends. Could you find all these people in this case?

* To solve this follow-up, we will first combine all the IDs from the two columns into one column and save this in a CTE. Then, we will count the occurrences of each ID as before.
    
* Instead of using the ORDER BY and LIMIT combination, we will use `DENSE_RANK()` over the count of IDs when grouped by ID. This will give us each ID, their occurrence count, and their rank. We will save this in another CTE.
    
* Finally, we will select the IDs and their occurrence counts where the rank equals 1.
    

### Solution Code:

```sql
WITH mixed AS (
    SELECT requester_id AS id FROM RequestAccepted
    UNION ALL
    SELECT accepter_id AS id FROM RequestAccepted
),
ranked AS (
    SELECT 
        id, 
        COUNT(*) AS num,
        DENSE_RANK() OVER(ORDER BY COUNT(*) DESC) AS ranks
    FROM mixed
    GROUP BY id
)

SELECT id, num
FROM ranked
WHERE ranks = 1
```
